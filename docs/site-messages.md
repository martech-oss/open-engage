# サイトメッセージ

Websiteのサイトメッセージで、内容・CTAリンク・対象ページ・掲載期間と次の設定を保存し、公開します。サイトトラッキング設定で対象サイトのドメインを許可し、表示用スクリプトを埋め込んでください。トラッキング設定は有効にしますが、訪問者が追跡に同意する前でも全訪問者向けCTAを表示できます。

- **識別済みの連絡先**：追跡に同意し、Contactに結びついた署名済みの訪問者情報を持つ人に表示します。既存メッセージと設定を省略したAPI入力の既定値です。
- **すべての訪問者**：初回訪問者にも公開します。Contact・訪問者トークン・追跡同意は不要です。公開中・掲載期間内・ページ条件一致・許可ドメインの条件は同じです。
- **セッションに1回**：同意済みの場合はsessionStorageで再表示を抑止します。既定値です。
- **ページごと**：ページを読み込むごとに表示できます。どちらの設定も同じページ内の重複表示をメモリで抑止します。

未同意時は識別情報の取得・保存、表示やクリックの個人イベント送信、計測のためのストレージ保存を行いません。そのため「セッションに1回」でも、未同意時やストレージを利用できない場合の抑止範囲は現在のページ内だけです。CTAのリンクと閉じるボタンは計測が拒否・失敗しても機能します。追跡同意を撤回すると、識別済み専用の表示を取り除き、未完了の識別済み応答を表示せず、それ以降のクリックイベントも送信しません。

対象ページは `*` で全ページ、`/pricing*` で料金ページ配下を指定します。掲載期間はワークスペースのタイムゾーンで入力し、UTCに変換して保存します。開始・終了の境界時刻を含み、終了は開始より後に指定します。

設置コードの初期値は `consent: false` です。同意取得時に `window.openengage.consent(true)`、撤回時に `window.openengage.consent(false)` を呼びます。スクリプト読込前なら `window.openengageSettings.consent` を更新してください。

## 計測の制限

表示数・クリック数・クリック率に含むのは、追跡同意がありContactを識別できる訪問者だけです。全訪問者向けCTAの実際の表示数・クリック数の総数ではありません。匿名・未同意の利用者の成果はこのカウンターでは測定できません。表示だけではContact・site_visitors・visitor_bindings・contact_eventsを作成しません。

公開GETは有効なHTTP(S)ページURLと許可ドメインを検証し、Originがある場合はそれも検証します。OriginのないリクエストもページURL検証を必須とします。識別済み専用の内容は、同意と当該ワークスペースの有効な識別情報がそろう場合だけ返します。結果はキャッシュしません。既存イベントPOSTは引き続き同意と識別を検証します。

## Migration

`packages/database/migrations/0027_anonymous_site_messages.sql` は `site_messages` に `audience` と `frequency` を追加します。既存行には `identified` / `session` を設定します。0026の後に[通常のD1 migration手順](../README.md#3-d1-migration)で適用してください。`pnpm db:migrate:local` または対象DBを確認したうえで `pnpm db:migrate:remote` を実行すると、未適用の0026・0027を順番に適用します。この実装作業では既存のローカルDBやリモートDBへのMigration適用・デプロイは行っていません。
